# OpenWithAssociatedApp

AviUtl ExEdit2 用の汎用プラグインです。タイムライン上のオブジェクトを右クリックして、その素材ファイルを外部アプリケーションで開けるようにします。

## 機能

- オブジェクト右クリックメニューに `プラグイン -> 対応ソフト` を追加します。
  - 選択中オブジェクトのエイリアスデータから素材ファイルパスを探して開きます。
  - 「拡張子設定」で登録済みの拡張子は登録した外部アプリケーションで、未設定の拡張子は OS の関連付けで開きます。
- オブジェクト右クリックメニューに `プラグイン -> アプリ実行 -> (アプリ名)` を追加します。
  - 「アプリ実行設定」に登録したアプリがリスト順に表示され、拡張子に関係なくそのアプリで素材を開けます。

## 動作環境

- AviUtl ExEdit2 beta49 以降

## インストール

[Releases](../../releases) から `OpenWithAssociatedApp.au2pkg.zip` をダウンロードして AviUtl2 のパッケージ機能でインストールするか、`OpenWithAssociatedApp.aux2` を Plugin フォルダに手動で配置します。

ポータブル構成の場合は `(AviUtl2のフォルダ)\data\Plugin\OpenWithAssociatedApp\` に配置します。

設定は `OpenWithAssociatedApp.aux2` と同じフォルダの `OpenWithAssociatedApp.ini` に保存されます。

## 使い方

### 拡張子設定

拡張子ごとに起動するアプリを登録します。プラグイン設定の `拡張子設定` を開き、次の手順で登録します。

1. `拡張子` に拡張子を入力します(例: `png`、`.png` どちらでも可)。
2. `アプリ候補` に、その拡張子を開けるインストール済みアプリの一覧が自動表示されるので選択します。候補にない場合は `参照...` から exe を指定するか、`実行アプリ` 欄に直接入力します。
3. `追加/更新` でリストに登録します。
4. リストの行をクリックすると内容が入力欄に読み込まれ、編集して `追加/更新` で上書きできます。`削除` ボタンまたは Delete キーで行を削除します。
5. `OK` で保存します。

登録例:

```text
.png -> C:\Program Files\paint.net\paintdotnet.exe
.wav -> C:\Program Files\Audacity\Audacity.exe
```

アプリケーション欄に `{file}` を含めると、その位置に素材ファイルパスを差し込んで起動します。

```text
.png -> C:\Tools\viewer.exe --open {file}
```

### アプリ実行設定

拡張子に関係なく素材を開くアプリのリストを登録します。

1. プラグイン設定の `アプリ実行設定` を開きます。
2. `実行アプリ` を `参照...` で選択します(`名前` が空欄なら exe 名が自動入力されます)。`{file}` も使えます。
3. `追加/更新` で登録します。同じ名前で登録するとコマンドを上書きします。
4. `上へ` / `下へ` でメニューの表示順を変更できます。
5. `OK` で保存します。

登録したアプリは、オブジェクト右クリックの `プラグイン -> アプリ実行 -> (アプリ名)` にリスト順で表示され、選択するとそのアプリで素材を開きます。

※メニューの表示名・順番・数の変更は AviUtl2 の再起動後に反映されます(保存時に再起動するか確認します)。コマンド内容の変更だけなら再起動なしで反映されます。登録できるメニューは最大 32 件です。
